### 🎞️ DaVinci Resolve Import Guide
  1. Unzip the Download: Extract the folder named [YourText]_sequence.
  2. Media Pool Import: Open Resolve, go to the Media tab or Edit tab.
  3. Locate Sequence: In the Media Storage browser, find the folder. Resolve will display it as a single file (e.g., frame_[000-095].png).
  4. Verify Frame Rate: Right-click the item in the Media Pool > Clip Attributes. Ensure the Frame Rate matches your project (e.g., 24fps).
  5. Place on Timeline: Drag the sequence onto a track above your footage. The transparency is baked in!
